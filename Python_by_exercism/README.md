# Python by Exercism

โฟลเดอร์เก็บโจทย์/คำตอบจาก [Exercism.org](https://exercism.org) Python track ที่ฝึกผ่านเครื่อง local ด้วย `exercism` CLI (ไม่ใช้ web editor) — เป็นช่องทางฝึกปูพื้น Python สำหรับเฟส 1 ของ [DE Roadmap](../filemd/02_DE_Roadmap_Phases.md)

## วิธีใช้
```bash
exercism download --exercise=<ชื่อโจทย์> --track=python
```
ดาวน์โหลดโจทย์มาไว้ที่ default path ของ exercism CLI แล้วค่อยย้าย/ลิงก์เข้ามาเก็บในโฟลเดอร์นี้ (หรือตั้ง workspace ของ exercism ให้ชี้มาที่นี่โดยตรง) แต่ละโจทย์แก้เสร็จแล้ว submit กลับด้วย:
```bash
exercism submit <path/to/solution.py>
```
