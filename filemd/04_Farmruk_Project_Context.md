## Farmruk คืออะไร

โปรเจกต์ธุรกิจที่ส่งแข่งขัน **"ฮักแม่ Hackathon"** ภายใต้ธีม *"สืบสานมรดกแม่แห่งแผ่นดิน สู่เศรษฐกิจชุมชน"*
เป็นแพลตฟอร์มที่ผสาน **โดรนติดเซ็นเซอร์วัดค่าดิน (NPK + ความชื้น) + กล้อง Multispectral** เข้ากับ **AI วิเคราะห์/แนะนำ** เพื่อเปลี่ยนเกษตรกรรมแบบ "ลองผิดลองถูก" ให้เป็น **"เกษตรที่ขับเคลื่อนด้วยข้อมูล" (Data-Driven Agriculture)**

## ปัญหาที่แก้ (Problem)

| Pain Point | รายละเอียด |
|---|---|
| ผลผลิตตกต่ำ | เกษตรกรไม่รู้สภาพดินรายโซนจริง → ปลูกพืชผิดชนิดกับดิน/ใส่ปุ๋ยผิด |
| ผู้สูงอายุครองส่วนใหญ่ | ขาดทักษะเทคโนโลยี ต้านทานการเปลี่ยนแปลง |
| Invisible Costs | ต้นทุนที่มองไม่เห็น (ปุ๋ยผิดชนิด, ยาผิดจุด) ทำให้วางแผนการเงินไม่ได้ |
| **(ยืนยันจากลงพื้นที่จริง)** โรค/แมลง/หญ้า | หลังสัมภาษณ์เกษตรกรจริงที่สุพรรณบุรี พบว่านี่คือ pain เร่งด่วนกว่าการเลือกพืชปลูก — โรคแส้ดำในอ้อย, แมลงระบาด, หญ้ารุกราน, ภัยแล้ง, ราคาอ้อยตก |

## กลุ่มเป้าหมาย

เริ่มต้นแบบ B2B: **Phase 1** — Agri-Landlord ที่ดินพืชไร่ขนาดกลาง-ใหญ่ (50+ ไร่) → **Phase 2** — สหกรณ์/ธุรกิจเกษตรขนาดกลาง → **Phase 3** — Agro-Industrial Enterprise (เช่น มิตรผล, CP Agro)

**พื้นที่ Pilot จริง:** อำเภอด่านช้าง จังหวัดสุพรรณบุรี (พืชหลัก: อ้อย — contract farming กับโรงงานมิตรผล) และขยายเพิ่มที่ อ.บ่อพลอย จ.กาญจนบุรี

## โซลูชัน / โปรดักต์

- **Drone + Sensor แบบ Integrated** — วัด pH/NPK/ความชื้นแบบ real-time
- **AI Crop Recommendation** — แนะนำ Top 3 พืชที่เหมาะกับแต่ละโซนดิน
- **Yield Forecast + BEP Report** — พยากรณ์ผลผลิตและจุดคุ้มทุน
- **Plant Health Report** (Core Feature อันดับ 1) — โรคพืช/แมลง/วัชพืช ตรวจด้วยกล้อง Multispectral + ดัชนี SRPI, NPCI, NGBDI
- **Free Demo Mode (Tier 0)** — บิน 1 ครั้งฟรี + Quick Scan Report (NDVI heatmap) เพื่อสร้าง Proof of Value ก่อนขาย

## Field Validation (2026-06-26)

สัมภาษณ์เกษตรกรจริง 2 ราย ที่ด่านช้าง สุพรรณบุรี — ยืนยันว่าเกษตรกรไม่มีข้อมูลดินจริง ใส่ปุ๋ย/ยาตามประสบการณ์ รายได้ไม่แน่นอน และ **Insight สำคัญที่สุด: ปัญหาไม่ใช่ราคา — ปัญหาคือขาด Proof of Value** เกษตรกรยังไม่เชื่อว่า Farmruk จะสร้างผลลัพธ์จริง

## สถานะปัจจุบัน (Traction)

- ✅ ได้รับอนุญาตให้ใช้โดรนสำรวจพื้นที่ pilot แล้ว (สุพรรณบุรี ด่านช้าง)
- ✅ มี BMC, Use Case, Impact slide, สัมภาษณ์เกษตรกรจริง 2 รอบ
- ❌ ยังไม่มีตัวเลข: จำนวน user, revenue, จำนวนไร่ที่สำรวจจริง, ผลผลิตก่อน-หลัง

## จุดเชื่อมกับ Data Engineering (ทำไมใช้ Farmruk เป็นแกนพอร์ต DE)

| ความต้องการจริงของ Farmruk | โจทย์ DE ที่ต่อยอดได้ |
|---|---|
| ข้อมูลดิน (pH/NPK/ความชื้น) รายพิกัด/รอบสำรวจ | Batch ingestion → S3 → clean/validate ด้วย Python/Pandas (เฟส 1-2) |
| ภาพสำรวจโดรน (Multispectral) หลายรอบ ตามฤดูกาลเก็บเกี่ยว | Pipeline ที่ schedule อัตโนมัติผ่าน Airflow ต่อรอบสำรวจ (เฟส 3) |
| ข้อมูลภาคสนามที่มักไม่สมบูรณ์ (ค่าดินขาด, ไฟล์เพี้ยน) | Data quality checks (schema/null/uniqueness) ด้วย dbt tests (เฟส 4) |
| "ข้อมูลอ้างอิงมาจากไหน เชื่อถือได้แค่ไหน" (คำถามจากเกษตรกรจริง) | Data modeling ที่ traceable กลับไปแหล่งข้อมูลต้นทาง (star schema เชื่อม LDD/data.go.th ใน `05_Farmruk_Data_Sources.md`) |

ดูแหล่งข้อมูลดิน/โดรน/โรคพืชที่ใช้จริงได้ใน [05_Farmruk_Data_Sources.md](05_Farmruk_Data_Sources.md)
