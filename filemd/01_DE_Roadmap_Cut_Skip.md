## สิ่งที่ข้ามได้เพราะหลักสูตร SIT ครอบคลุมอยู่แล้ว

| หัวข้อใน roadmap เดิม | ครอบคลุมโดย |
|---|---|
| Linux Fundamentals, shell scripting (Week 4, 7-8) | INT134 System Deployment (Linux VM, systemctl, journalctl, shell) ที่กำลังเรียนอยู่ |
| SQL basics–intermediate, Data Modeling/star schema (Week 5-8) | Basic SQL (ปี 1) + INT291 Physical Database Concepts and Design (สาย DE) |
| Big Data Architecture | INT296 Big Data Architecture (หลักสูตร DE) |
| NoSQL Database | INT297 NoSQL Database (หลักสูตร DE) |
| Data Warehouse & OLAP | INT294 Data Warehouse and OLAP (หลักสูตร DE) |
| Relational DB, Git พื้นฐาน | มีประสบการณ์แล้วจาก INT134 (MySQL, Prisma) และงานกลุ่ม INT191 |

> ⚠️ **สำคัญ:** ตอนนี้ Gun อยู่แค่**ปี 2** วิชา INT291/INT294/INT296/INT297 ในตารางข้างบนส่วนใหญ่ยัง
> เป็น**วิชาอนาคตที่ยังไม่ได้ลง** ไม่ใช่วิชาที่เรียนแล้ว/รู้แล้ว — "ข้ามได้" ในที่นี้หมายถึง
> "ไม่ต้องเรียนเชิงลึกซ้ำตอนนี้เพราะหลักสูตรจะสอนอยู่แล้วในอนาคต" ไม่ใช่ "Gun เชี่ยวชาญแล้ว"
> ส่วนหัวข้อที่เรียนผ่านมาแล้วจริง (เช่น Basic SQL ปี 1, Git จาก INT191) ก็ยัง**ต้องทบทวนใหม่เสมอ**
> ก่อนเริ่มใช้งานจริง ไม่ควรสันนิษฐานว่าคล่องอัตโนมัติ

**นัยสำคัญ:** เวลาที่ roadmap เดิมใช้ 4+ สัปดาห์กับพื้นฐานเหล่านี้ ทวนเร็วๆ ได้ภายใน 1-2 สัปดาห์ (โดยเช็คระดับความเข้าใจจริงก่อนเสมอ) แล้วเอาเวลาไปทุ่มกับสิ่งที่ยังไม่มีจริงๆ คือ **Python เชิงลึกสำหรับ DE, Cloud hands-on, Orchestration (Airflow), Spark, dbt** — รายละเอียดแผนอยู่ใน [02_DE_Roadmap_Phases.md](02_DE_Roadmap_Phases.md)
